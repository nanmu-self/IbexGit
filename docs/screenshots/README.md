# 截图

README 中引用的界面截图。截图规范：

- 深色主题，窗口宽度 1280–1440px，PNG
- 使用包含多分支 / 标签 / 图片改动的演示仓库，避免空仓库
- 文件名与用途：

| 文件 | 页面 |
|------|------|
| `01-workspace-diff.png` | 工作区 + 统一 diff（行级暂存、词级差异、Shiki 高亮） |
| `02-history-graph.png` | 提交历史 + SVG 提交图 |
| `03-image-diff.png` | 图片 diff（滑动对比） |
| `04-ai-report.png` | AI 助手：日报 / 周报生成（跨仓库聚合） |
| `05-welcome-repos.png` | 仓库总览（分组、彩色书签） |

可选补充：提交统计对话框、命令面板、冲突解决编辑器。
